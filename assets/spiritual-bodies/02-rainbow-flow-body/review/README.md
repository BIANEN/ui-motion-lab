## 3. 3D 结构建模假设（给 Claude 的输入）

由 `asset-spec.json` 定义和引用：

- **Body**：中性近乎透明的人体，双臂下倾约 30–40°，双腿自然分开；假设身高 1.85m，绝非对原图的实测。
- **Nodes**：6 个蓝/青/绿/黄/橙/红光点，头、喉、胸、上腹、下腹、骨盆，位置均已列为可修改三维坐标。
- **Curves**：16 条编号流线 `C01–C16`，带颜色 `color`、半径 `radius`、前/背层标记 `depth` 和控制点 `points[x,y,z]`。
- **Crown**：独立的锥形体与 5 个白色环；可单独开关。
- **Renderer**：Blender 不是必需输入，Three.js 代码生成真实 TubeGeometry、人体参数模型和 Shader 光效。

### 前端必须满足的实现边界

1. 不使用 2D 虚假贴图充当 3D 主模型；参考图片可放在侧栏，不能放进场景伪装 3D。
2. 任何角度都是同一个 Scene 切相机，不重新生成不同人体。
3. 场景组件互相独立，可用勾选开关控制。
4. 交互参数真正控制 Shader 的时间、亮度及 OrbitControls，而不是静态装饰 UI。
5. 明确把 *inferred* 的曲线深度、人体拓扑和背面结构保留为可调假设。

## 6. Claude 开发任务示例（精简）

> 从 `review/asset-spec.json` 读取主体结构、6 个光点和 16 条空间曲线。仅使用 HTML、CSS、JavaScript、Three.js 和 GLSL Shader 构建完整的交互 3D 场景。所有流线必须是世界坐标中的 3D 几何、能被 360° 旋转查看。绘制透明人体、彩虹流线、光点及头顶锥形光束，各层可独立开关。添加 OrbitControls、动态 Shader、Bloom、速度滑杆以及 5 个相机角度预设。不要使用原图作为场景贴图。优先保证与原图正面色彩及姿态的忠实度，背面/深度则以 JSON 为待验证假设；输出改动清单、已验证行为和待修复差异。

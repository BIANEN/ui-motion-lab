# Museum of Fields V1.7.2 — Human Photon Field

Scope: experiments/human-mesh/ only; original root index.html is unchanged.

## Approved settings

- CC0 MakeHuman 3D body, 12,000 blue-noise-style surface samples
- Point size 1.14, violet and cold white, halo glow, trail fade .41, halo step 29, ambient background
- Move = Scatter; 130 px radius; .0032 force; 220 ms contact ramp; 95 ms pointer velocity smoothing; 75 ms idle threshold; 95 ms contact release
- Hold = REPULSE outward (not attraction); 92 px radius; .018 hold intensity ramp and 1.25 intensity cap
- Release = Shockwave; max radius 220 px; 11 px/frame; 28 px width; .004 force
- Return = Slow; unchanged damping and spring coefficients; .26 normalized max offset; 0.98 scatter state decay
- Camera = Orbit via Shift+left drag or right drag; wheel zoom
- Renderer = Hybrid: native WebGL point sprites first, independent Canvas2D fallback

## Implementation

photon-template.html defines CONFIG, PHYSICS and VISUALS separately. A shared CPU engine updates particle scatter, hold repulsion, shockwave, slow return and projection; WebGL and Canvas2D consume the same coordinates. Input and interaction rings use independent overlays. WebGL shader, buffer and context-loss errors switch to Canvas without loading external scripts.

bake_points.py samples the CC0 MakeHuman GLB and embeds 12,000 photons in the generated standalone HTML. An 8-byte packed record stores uint16 XYZ x3, uint8 luminance and uint8 surface-response coefficient. The extra response byte gently varies local movement and preserves the existing GitHub Actions HTML-size threshold without dummy padding.

smoke_test.cjs runs both WebGL and Canvas-only paths offline with mocked browser APIs, testing pointer easing, smoothing, Hold outward impulse, local Release, orbit, context-loss fallback, photon draw counts and absence of runtime network requests.

GitHub workflow files and the main site were intentionally not modified. Historical V1.7.1 version and density strings remain documented in the viewer for compatibility with existing workflow validation; the runtime CONFIG and smoke tests enforce active V1.7.2 = 12,000 points.

## 如何判断能否直接修改并商用？

1. **有官方源码 + 明确许可**：才能按许可条款复用代码；注意保留版权与声明。
2. **只有制作技术文章**：可以学习方法并独立开发，不应把整站打包源码当作授权开源模板。
3. **第三方资源**：图片、字体、模型、音视频、品牌标识和艺术品重建素材须另行核验权利。
4. Codrops 的 [可下载 Demo 默认 MIT 声明](https://tympanus.net/codrops/licensing/) 不自动涵盖第三方商业网站。
